# Design System — EletroTech

## Portal Educacional de Eletroeletrônica

---

## 1. Identidade Visual

**Nome:** EletroTech

**Tema:** Circuitos Integrados (CIs)

**Estilo:** Clean, moderno, tecnológico e educacional.

O site foi desenvolvido para apresentar conhecimentos sobre **Circuitos Integrados** de forma simples, organizada e visualmente agradável.

A interface utiliza elementos inspirados em componentes eletrônicos, mantendo uma aparência profissional sem excesso de elementos decorativos.

### Logotipo

O logotipo representa um **Circuito Integrado (CI)**.

Características:

- Chip em azul escuro
- Letras "CI" em branco
- Trilhas eletrônicas em azul/ciano
- Pequeno destaque amarelo
- Nome EletroTech ao lado do símbolo

A logo aparece no Header e possui tamanho reduzido para manter a navegação limpa.

---

# 2. Estrutura do Site

A estrutura principal utilizada no site é:

**Header → Sidebar + Main → Footer**

O Header apresenta os principais elementos de navegação.

- Início
- Circuitos Integrados

# 3. Sidebar

A Sidebar funciona como o menu principal de navegação do conteúdo.

### Itens

- Início
- O que são CIs?
- Como funcionam
- Estrutura
- Tipos de CIs
- Aplicações
- Vantagens
- Curiosidade
- Quiz
- Referências

O item relacionado à área atualmente selecionada recebe destaque visual.

### Estado normal

- Fundo transparente
- Texto em azul escuro
- Bordas arredondadas

### Estado Hover

Quando o usuário passa o mouse sobre um item:

- Fundo muda para azul claro
- Texto muda para `#00A8E8`
- Item desliza levemente para a direita
- Texto fica mais destacado

A animação é rápida e discreta.

### Estado ativo

O item selecionado pode utilizar:

- Fundo `#00A8E8`
- Texto branco
- Pequeno detalhe amarelo `#FFC107`

# 6. Paleta de Cores

| Nome | Código | Utilização |
|---|---|---|
| Azul Escuro | `#0B1F33` | Header, Sidebar, títulos |
| Azul/Ciano | `#00A8E8` | Links, botões, hover e elementos interativos |
| Amarelo | `#FFC107` | Destaques e detalhes |
| Fundo | `#F4F7FA` | Fundo geral |
| Branco | `#FFFFFF` | Cards e áreas de conteúdo |
| Texto | `#172B4D` | Textos principais |
| Texto Secundário | `#64748B` | Informações auxiliares |

### Regra de utilização

O **azul escuro** é a principal cor estrutural.

O **azul/ciano** representa interação e tecnologia.

O **amarelo** é utilizado somente para chamar atenção para informações específicas.

O branco é utilizado nos cards para criar contraste com o fundo.

---

# 9. Interação dos Cards

Os cards possuem efeito de **Hover**.

Quando o usuário passa o mouse:

- O card sobe levemente
- A borda recebe destaque azul/ciano
- A sombra aumenta discretamente
- A transição ocorre de forma suave

O objetivo é indicar que o elemento possui interação sem utilizar animações exageradas.

---

# 10. Botões

O site utiliza três estilos principais.

## Botão Principal

Cor:

`#00A8E8`

Exemplo:

**Começar estudo**

Ao passar o mouse:

- Fica ligeiramente mais escuro
- Sobe alguns pixels
- Recebe uma sombra azul discreta

---

## Botão de Destaque

Cor:

`#FFC107`

Exemplo:

**Fazer Quiz**

O amarelo é reservado para ações que precisam de maior destaque.

---

## Botão Secundário

Características:

- Fundo branco
- Borda azul
- Texto azul escuro

Exemplo:

**Ver referências**

Ao passar o mouse:

- Fundo fica azul/ciano
- Texto fica branco
- Botão sobe levemente

# 17. Elementos Visuais

O site utiliza elementos inspirados em circuitos eletrônicos.

Exemplo:

```text
●────────●
│        │
├── CI ──┤
│        │
●────────●
```

Esses elementos devem aparecer de maneira discreta.

Podem ser utilizados em:

- Hero
- Cards
- Títulos
- Background
- Seções especiais

Não devem ocupar espaço excessivo.

---

# 18. Efeitos de Hover

Os elementos interativos possuem feedback visual.

### Menu

Ao passar o mouse:

- Mudança de cor
- Fundo azul claro
- Pequeno deslocamento para a direita

### Cards

Ao passar o mouse:

- Elevação
- Borda azul
- Sombra suave

### Botões

Ao passar o mouse:

- Mudança de cor
- Pequena elevação
- Sombra

### Links

Ao passar o mouse:

- Mudança para azul/ciano
- Transição rápida

As transições devem ser aproximadamente de `0.25s`.

---

# 19. Responsividade

O site deve funcionar em:

- Desktop
- Notebook
- Tablet
- Celular

### Tablet

Os cards podem ser reorganizados em menos colunas.

### Celular

- Sidebar pode ser adaptada ou recolhida
- Cards passam para uma coluna
- Header é reorganizado
- Campo de pesquisa se adapta à largura
- Botões ocupam espaço adequado
- Textos continuam legíveis
- Imagens não ultrapassam a tela

---

`#0B1F33`

---

# 21. Direção Visual

O site deve transmitir:

**TECNOLOGIA + EDUCAÇÃO + ELETROELETRÔNICA**

A aparência deve ser:

- Clean
- Moderna
- Tecnológica
- Educacional
- Organizada
- Fácil de navegar
- Profissional

---

# 22. Elementos que devem ser evitados

O projeto não deve utilizar:

- Excesso de cores
- Excesso de animações
- Muitos elementos decorativos
- Textos muito pequenos
- Cards muito carregados
- Uso exagerado do amarelo
- Sombras muito fortes
- Gradientes excessivos
- Animações demoradas
